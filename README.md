# 破牢之靴（Boot Breaker）自动 bot

Dota 2「暗黑狂欢」小游戏破牢之靴（打砖块）的屏幕识别 + 模拟按键 bot。
实测：一局 29 分钟打到第 27 关，分数超过 20000（奖励档），全程 7 次掉球。

## 使用
1. Dota 2 窗口模式，进入破牢之靴。
2. 第一次用：运行 `record.bat`，鼠标指向游戏窗口左上角按 F8、右下角按 F9（框应约 936×927），生成 `config.json`。
   之后窗口位置大小不要变。`run_bot.bat` 里也可以用 F8/F9 重框。
3. 运行 `run_bot.bat`，切回 Dota 按 **F6** 开始/暂停，**F7** 截图到 `debug/`，**F10** 退出。
4. 自动发球、接球，游戏结束自动点“再玩一次”。不需要锁帧。
5. 依赖：`..\dota_automaton\.venv`（mss, keyboard, numpy, opencv-python）。

## 原理
- **识别**（只截场地区域，约 57 帧/秒）
  - 球 = 棕色靴子 + 蓝色光弧同时出现（只认棕色会认成两侧爪子）
  - 挡板 = 红色车顶（y≈798–816）
  - 游戏结束 = 模板匹配 `replay_btn.png`
- **跟踪**：保留上次反弹以来最多 40 个点，用线性拟合求位置和速度。
  - 靴子旋转会让中心点抖动约 ±13px，游戏帧节奏也不均匀，所以点不能太少：12 点时落点误差 46px，40 点时约 20px。
  - 反弹判定：新点偏离预测 >45px，或走向与拟合速度夹角 >70°。
- **落点预测**：直线外推到 y=770，左右墙（x 175/757）镜像折叠。
- **挡板控制**：
  - 按住方向键会加速（0.2 秒后约 800 px/s，最高 ~1200），松键后还会滑 20–30px，所以提前松键（刹车距离 15+0.08·|v|）。
  - 球短暂丢失 ≤0.4 秒时继续朝最后的目标移动；刚扔出、还没认出球时挡板回中间。
- **静止误检**：半空静止 >0.6 秒的目标视为误检（冰砖和橙砖相邻处），在本关内忽略该位置；但不屏蔽正在跟踪的球。
- **按键**：必须用扫描码 SendInput。`keyboard` 库发的方向键 Dota 收不到。

## 文件
- `bb_bot.py`：bot 本体
- `recorder.py` / `record.bat`：录屏（30 帧/秒 + 按键记录），用于分析
- `analysis_offline.py`：用 `frames/` 录像离线验证落点预测
- `analysis/misses.py runs/<run>.csv`：列出一局里每次掉球的现场
- `analysis/replay_pred.py runs/<run>.csv`：用实机日志回放，评估落点预测精度
- 运行日志存在 `runs/`，异常/每关截图存在 `debug/`（都不进仓库）

## 已知局限
- 后期球速约 1000 px/s，球在中下部撞砖变向后留给挡板的时间很短，偶尔接不到。
- 不控制发球和反弹角度，清关靠随机反弹，每关 1–2 分钟。
- Valve 用户协议禁止自动化脚本，有封号风险，自行判断。
